# Herrera Perfumes Manager — HTML, CSS y JavaScript

Versión académica convertida para la Entrega 2. No utiliza React, TypeScript, Bootstrap, Tailwind ni librerías de interfaz.

## Cómo abrirlo
1. Descomprime `herrera-perfumes-html-css-js.zip`.
2. Abre la carpeta `herrera-perfumes-html-css-js` en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes usar la extensión Live Server si ya la tienes instalada; no es necesaria para el proyecto.
4. Para publicar en GitHub Pages, sube los archivos y carpetas de esta carpeta al repositorio.

## Carpetas
- `index.html`: estructura y vistas.
- `css/estilos.css`: estilos principales.
- `css/componentes.css`: archivo reservado para separar estilos de componentes.
- `css/responsive.css`: adaptación a celular y tableta.
- `js/productos.js`: datos de ejemplo del catálogo.
- `js/app.js`: navegación, inicio, categorías, detalle y confirmación.
- `js/inventario.js`: búsqueda, filtros y orden de productos.
- `js/validaciones.js`: validación de formularios con mensajes visibles.
- `img/catalog/`: imágenes incluidas en el ZIP original.

## Importante para la entrega
Los datos solo se mantienen mientras la página está abierta; no hay base de datos ni guardado permanente, tal como pide la entrega. Los perfumes nuevos usan una imagen de muestra. Los precios y el catálogo son datos demostrativos y debes revisarlos contra el inventario real de tu emprendimiento antes de entregar.

Las fuentes de Google Fonts se cargan desde internet; si no hay conexión, el sitio usa fuentes alternativas del sistema.
